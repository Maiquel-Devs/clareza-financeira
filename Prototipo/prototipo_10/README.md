# Protótipo — Clareza Financeira V23

Abra `index.html` no navegador.

## Ajuste desta versão

As listas de movimentações agora deixam mais claro que cada item é clicável.

Foi adicionado:
- um **chevron discreto à direita** de cada movimentação;
- leve feedback visual no hover/toque.

Exemplo:

`Mercado   R$ 650,00   >`

Isso vale tanto para:
- listas de despesas;
- listas por origem de renda.

A estrutura da lista continua limpa e sem transformar cada item em um card pesado.
