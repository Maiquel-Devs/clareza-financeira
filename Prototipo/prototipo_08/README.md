# Protótipo — Clareza Financeira V22

Abra `index.html` no navegador.

## Ajuste desta versão

O gráfico de despesas do Dashboard agora fecha automaticamente ao sair da tela.

Exemplo:
1. o usuário abre `Ver gráfico das despesas`;
2. navega para outra tela;
3. ao voltar ao Dashboard, o gráfico aparece recolhido novamente.

A regra vale sempre que o usuário deixa o Dashboard para abrir outra tela.

Nenhum cálculo foi alterado.
