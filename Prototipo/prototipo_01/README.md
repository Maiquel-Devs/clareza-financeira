# Protótipo — Clareza Financeira

Abra `index.html` no navegador.

Arquivos:
- `index.html`: telas e componentes
- `style.css`: visual mobile
- `app.js`: banco simulado, cálculos, recorrências e interações

O protótipo é descartável e não representa a arquitetura final Android.

O JavaScript simula:
- receitas e despesas pontuais;
- receitas e despesas recorrentes;
- exceções mensais;
- alterações recorrentes a partir de um período;
- interrupção de recorrência preservando histórico;
- cálculo de renda, despesas, sobra/excesso, percentual e categorias.

Também inclui a hipótese "Explorar primeiro" e permite meses futuros para que esses dois comportamentos possam ser avaliados no protótipo.
