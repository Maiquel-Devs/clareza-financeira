# Protótipo — Clareza Financeira V13

Abra `index.html` no navegador.

## Ajustes desta versão

O botão `+` do topo do Dashboard também foi trocado para SVG.

Também foi feita uma revisão dos ícones compactos para manter o mesmo padrão visual nos botões pequenos:
- `+` do Dashboard;
- calendário do Histórico;
- setas internas;
- setas de ano;
- `+` e `−` das opções de adicionar movimentação.

A intenção é evitar desalinhamentos visuais causados por símbolos dependentes da fonte.
