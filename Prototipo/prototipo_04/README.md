# Protótipo — Clareza Financeira V9

Abra `index.html` no navegador.

## Mudanças desta versão

### 1. Fluxo da renda corrigido

A renda agora segue o mesmo padrão das despesas.

Exemplo:

`Dashboard → Salário → lista das movimentações de Salário → detalhes`

Isso deixa o fluxo consistente com:

`Dashboard → Saúde → Academia → detalhes`

Mesmo quando existe apenas uma movimentação de Salário, a lista intermediária continua aparecendo.

### 2. Setas internas padronizadas

As setas antigas com fundo/quadrado pesado foram substituídas pelo mesmo padrão leve já aprovado no Histórico.

A mudança foi aplicada em:
- listas;
- detalhes;
- formulários;
- telas internas de navegação;
- primeiro acesso;
- retorno de fluxos internos.

A área de toque continua confortável, mas visualmente a seta fica mais limpa.

## Fluxos de referência

### Despesas
`Categoria → lista de despesas da categoria → movimentação → detalhes`

### Renda
`Origem da renda → lista das movimentações daquela origem → movimentação → detalhes`
